# بقالة العزي للمواد الغذائية — نقطة بيع ومحاسبة (React Web App)

تطبيق نقطة بيع ومحاسبة وإدارة المخزون والعملاء لبقالة العزي للمواد الغذائية، مُعاد بناؤه باستخدام **React 18 + TypeScript + Vite + Tailwind CSS**.

## المميزات والوظائف
- **واجهة كاملة باللغة العربية مع دعم RTL** ومطابقة للهوية البصرية (Material 3 + Primary Blue #1565C0).
- **إدارة فواتير المبيعات (POS)**:
  - ترقيم تسلسلي تلقائي للفواتير.
  - دعم الدفع النقدي والآجل (دين).
  - إضافة سريعة للأصناف مع اقتراحات من المخزون وحساب فوري للإجمالي.
- **سجل الفواتير**: استعراض، بحث وتصفية، تصدير بصيغة Excel (CSV متوافق مع الحروف العربية)، ومشاركة عبر WhatsApp وPDF.
- **إدارة العملاء والحسابات**:
  - سجل العملاء ومتابعة الديون المستحقة بالريال اليمني.
  - كشف حساب تفصيلي للعميل مع الفواتير المرتبطة وسجل السداد والدفعات.
  - تصدير كشف الحساب بصيغة صورة إيصال 58mm أو PDF أو مشاركة مباشرة عبر واتساب.
- **الأصناف والمخزون**:
  - متابعة المخزون وأسعار البيع.
  - تنبيهات الأصناف منخفضة المخزون.
  - تعديل المخزون المباشر وإضافة أصناف جديدة.
- **لوحة التقارير**: إحصائيات المبيعات اليومية (نقدي وآجل)، إجمالي ديون العملاء، وعدد الفواتير الكلي.
- **الطباعة الحرارية**: توليد إيصالات حرارية بعرض 58mm (384px) مطابقة لطباعة ESC/POS مع معاينة وطباعة مباشرة وتنزيل كصورة PNG.
- **دعم الوضع الداكن والفاتح (Dark / Light Mode)**.

## التشغيل والتطوير
```bash
npm run dev
```
التطبيق يعمل على المنفذ `3000`.

## بناء تطبيق أندرويد (Android APK)

### ١. البناء التلقائي عبر GitHub Actions:
- عند رفع المشروع إلى مستودع GitHub على فرع `main` أو `master`، سيقوم سير العمل `.github/workflows/build.yml` تلقائياً ببناء ملف تطبيق الأندرويد `Azizi-POS-Grocery.apk`.
- بعد انتهاء البناء (أيقونة خضراء)، ادخل على تبويب **Actions** في GitHub، ثم اضغط على أحدث تشغيل، وستجد ملف الـ APK جاهزاً للتنزيل في قسم **Artifacts** باسم `Azizi-POS-Grocery-APK`.

### ٢. البناء عبر Android Studio:
- افتح مجلد `android/` في برنامج **Android Studio**.
- اضغط على **Build > Build Bundle(s) / APK(s) > Build APK(s)** لإنشاء ملف الـ APK وتثبيته مباشرة على هاتفك.
